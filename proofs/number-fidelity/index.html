Right meaning, wrong number

Speech models are scored on word error rate. In a voice confirm, the only words that matter are the numbers. A transcript can be 95% right and still send a picker to the wrong slot.

The gap

  • Current Indic speech benchmarks don't score number accuracy. Sarvam and AI4Bharat's open Indic DiarBench covers about 28 hours across 10 main languages. It scores DER, cpWER and WDER. None of these isolates whether a quantity or check digit came out right.
  • Hindi-English number speech has specific traps. Saath is 60 but also means "with". 19, 29, 49 and 79 differ by one syllable. Paune teen means 2.75, not 3. Speakers switch language mid-number ("seven-saat-seven").
  • A missed number costs more than a missed word. Get the meaning right and the quantity wrong, and you have a mispick, a wrong delivery or a wrong payment.

The metric

Number Fidelity Error (NFE) = items where any expected numeric field is wrong after normalisation, divided by items attempted.

Normalise first: map Hindi number words and fractions to values, read "double"/"triple" as repeats, keep leading zeros, and let the last value win after a spoken correction ("nahi"). Then compare each field exactly. Partial credit doesn't exist, because a pick is either right or wrong.

Always report it as failures out of n, per model and per condition, e.g. "7 of 50 wrong". Never report a bare percentage.

Recording protocol

  • At least 2 speakers, each reading all 50 items, so n = 100 per condition.
  • Two conditions: a quiet room, and the same scripts over warehouse background noise (forklift reversing alarm, conveyor hum) played at a fixed level.
  • Read the way a picker talks: fast and flat, with no pause before the number.
  • Run the same audio through each speech-to-text system under test (e.g. Sarvam's speech-to-text API and Whisper). Keep the raw transcripts, so anyone can re-score them.

The 50 items

  • A Hindi words that sound like English words (items 1-10)
  • B Near-identical Hindi numbers (items 11-20)
  • C Fractions (dedh, dhai, sawa, paune) (items 21-30)
  • D Language switches inside a field (items 31-40)
  • E Check digits (items 41-50)

Where this goes beyond warehouses

There's no good data on how many Indian warehouses use voice picking. Most still use barcode scanners. The same number traps show up wherever Hindi-English speech carries a number that has to be exact: delivery-partner address calls, UPI payment confirmations, and order taking.
